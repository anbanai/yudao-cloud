# 微信官方物流助手打单

V1 使用微信小程序物流助手，不接入顺丰开放平台，也不运行自研 Go Agent。

## 运行链路

```text
trade 服务 -> system WxMaExpressService -> 微信物流助手 -> 微信打单 PC 软件 -> GS050DY 官方驱动
```

## 首次配置

1. 在微信小程序后台绑定已签约的顺丰月结账号。
2. 后台调用 `getAllAccount`，确认存在 `delivery_id=SF`、`status_code=0` 的账号，并记录返回的 `biz_id`、服务类型和余额。
3. 在 Yudao 后台保存 `biz_id`、服务类型、发件地址和默认包裹尺寸。月结卡号不能直接当作 `biz_id`。
4. 使用 `updatePrinter` 绑定打印员 OpenID，再用 `getPrinter` 验证绑定结果。
5. Windows 安装微信物流助手 PC 打单软件和得力 GS050DY 官方驱动，选择 203dpi、实际热敏纸尺寸和无缩放。
6. PC 软件登录打印员账号，选择对应商户，开启自动拉单和自动打印。

## 业务操作

1. 后台点击“创建微信物流运单”。服务端调用 `addOrder`，响应中的 `waybill_id` 才是运单号。
2. 微信 PC 软件自动拉取并打印面单。
3. 仓库确认标签已经打印后，点击“确认已打印并发货”。服务端调用现有交易发货流程，订单才进入“已发货”。

月结卡绑定本身不会生成运单号。没有执行 `addOrder` 时，后台显示“尚未创建微信物流订单”是正确状态。

## 常见错误

| 微信错误码 | 含义 | 处理 |
| --- | --- | --- |
| `9300525` | `biz_id` 未绑定 | 重新调用 `getAllAccount`，不要手填月结卡号 |
| `9300531` | `biz_id` 或密码无效 | 检查微信后台签约账号是否生效 |
| `9300501` | 顺丰业务错误 | 查看接口返回的快递侧错误信息并联系网点 |

顺丰月结账号使用固定揽件约定时，`addOrder.expect_time` 使用 `0`。散单 `SF_CASH` 需要预约时间，不适用于提前自动打印流程。

## 兜底

微信 PC 软件离线或面单打印失败时，运单保持“已创建、待确认打印”，不会自动发货。原有手工发货入口继续保留。
